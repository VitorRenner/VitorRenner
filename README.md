## Sobre mim

Sou estudante do 3º ano de Engenharia de Software e estagiário de back-end Python. No dia a dia construo APIs que coletam, tratam e entregam dados públicos de Joinville.

Gosto de código organizado: cada parte com uma responsabilidade, fontes de dados isoladas para que uma falha não derrube o sistema inteiro, e banco versionado com migrations.

- 🔭 Hoje: **Joinville Data Hub**, API de dados de emprego e empresas de Joinville
- 🌱 Estudando: testes automatizados, Docker e deploy em nuvem
- 🎯 Procurando: primeira vaga como **Desenvolvedor Back-end Jr**

## Projetos em destaque

### 📊 [Joinville Data Hub](https://github.com/VitorRenner/JoinvilleDataHub)
API em Python que coleta dados públicos de **emprego (CAGED)** e **empresas (IBGE/CEMPRE)** de Joinville, organiza tudo em PostgreSQL e entrega para o site Nexus. Cada fonte de dados roda isolada, então se uma quebrar, as outras continuam no ar.
`Python` `FastAPI` `PostgreSQL` `Alembic` `Docker`

### ⚡ EnergyOS · [Front-end](https://github.com/VitorRenner/Energyos-Front) · [Back-end](https://github.com/VitorRenner/EnergyosBackend)
Sistema IoT de monitoramento de energia residencial. Um ESP32 com sensor PZEM-004T mede tensão, corrente e potência, e um dashboard mostra o consumo em tempo real, com custo estimado e alertas. Projeto em equipe.
`React` `Vite` `Chart.js` `Java` `MQTT` `IoT`

### 🏀 [DraftStore E-commerce](https://github.com/VitorRenner/DraftStoreEcommerce)
E-commerce de artigos de basquete, com back-end em Python.
`Python` `E-commerce`

### 🤖 [Servidor MCP com IA](https://github.com/VitorRenner/Server-MCP-IA)
Implementação de um servidor MCP (Model Context Protocol) para a disciplina de Fundamentos de Inteligência Artificial.
`Python` `IA` `MCP`

### 🌐 [Site Aluguel de TI](https://github.com/VitorRenner/Frontend-Site-Aluguel-TI)

`Angular` `TypeScript` `HTML` `CSS`
